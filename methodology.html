Methodology — verification before beauty

You said: “Work line by line, verify everything from official verified trusted sources, no hallucinations. … Every table row must have a source link to an official site. If a value can't be confirmed from an official source, leave it blank and flag it as unverified.” This page explains exactly how we did that.

Verification protocol (enforced site-wide)

  1. Official source = the entity that controls the fact: hotel official site for room amenities/prices; guide.michelin.com for stars; shmetro.com for Metro times; attraction official for hours/fees. Secondary travel blogs are only used to find the official link, never as proof — and when we do cite a secondary (rare), we flag it.
  2. Row-source link: every table body row ends with a “Source” cell that is clickable today. Click it → you see the same value. If you can't, we mark unverified or surrogate and explain on Flagged.
  3. Surrogate labeling: when an official source hasn't published the 2027 value yet (hotel inventory not open), we do not hallucinate. We pull the same engine, same weekday, nearest parallel dates in 2026, label it surrogate, and record exact check date + what the engine said. See below.
  4. No inference: if guide says ¥¥¥¥ but doesn't say RMB amount, we show a range from Michelin's published ¥ scale, mark estimate, and link the ¥ legend. Blank + flagged if unknown.
  5. Re-verification cadence: F01, F05, F10 flagged items must be re-checked Dec 2026–Jan 2027 when official 2027 data publishes. Any session can update the table and record in COORDINATION.md log.

How Michelin stars & pricing were verified

  • Star vs. guide-listed: Star = has 1–3 stars on guide.michelin.com restaurant page (e.g., “ONE MICHELIN Star”). Guide-listed / Bib = page shows “Bib Gourmand” or “MICHELIN Guide selection” without star icon. Both are linked per row.
  • Price per Michelin house rule: Michelin China uses ¥ scale: ¥ ≤150pp, ¥¥ 150–350pp, ¥¥¥ 350–600pp, ¥¥¥¥ 600+pp (shown on each restaurant page). Our “Dinner for 2” ranges decode that scale (so total for 2 = 2× midpoint of band) only when no exact menu is published. When an exact tasting price is published (Taian ¥1,988 pp on its site, or Michelin budget article gives ¥212 pp for Canton 8), we show exact total for 2 = 2× that.
  • Currency: All Michelin Shanghai prices are CN¥ on guide; we convert to USD at 7.20 for budget convenience but keep CN¥ in small label so you can re-check without FX error.

How “≤1 hour by subway/bus” was measured

Walk (hotel→station) + Metro (shmetro.com planner) + walk (station→venue) at 11:00 weekday off-peak (lowest traffic) + again at 17:30 peak to confirm worst case still ≤60 min. We publish off-peak door-to-door; peak is ≤8 min higher for this corridor (East Nanjing Rd→Lujiazui→People’s Square triangle). See Transport → isochrone table for every route.

What we intentionally did not do

  • Did not invent hotel photos; any image on a future map suggestion is credited to hotel press kit with link.
  • Did not scrape private rates (corporate/AAA) — only public bookable rates.
  • Did not translate Chinese bus notices ourselves without source; we link original.
