Suggestions for future review

  1. Reconcile the independent datasets into one source-dated record per venue, distinguishing stars from guide selection.
  2. Add a dated quote comparison with room, cancellation and all taxes, rather than extrapolated starting prices.
  3. Build a route evidence matrix and rank only hotels with verified journeys and qualifying rooms.
  4. Audit individual social videos for the correct venue and review content; clearly mark missing reviews.
  5. Add automated checks for missing evidence, stale dates, broken internal links and contradictions across datasets.

These are proposals, not implemented changes. See the prior review register and other suggestions.
