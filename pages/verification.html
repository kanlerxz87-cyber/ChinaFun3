Verification rule

Every table row has a source link to an official site. If a value can’t be confirmed from an official source, it is left blank and flagged Unverified. Nothing is inferred. Verified = official source checked · Partial = some fields verified, others blank · Unverified = do not rely on it.

How to verify a blank cell (5 steps)

  1. Open the row’s official link.
  2. Find the exact field (price total, hours, closed day).
  3. Screenshot or copy the URL + date checked.
  4. Update data/*.csv, set verified=yes, commit.
  5. Rebuild the table from the CSV (single source of truth).
