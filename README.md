# China trip planner

Static, mobile-friendly research dashboard for a proposed Shanghai trip. Open `index.html` locally, or serve the repository root with any static server. All internal links are relative, so it works under a GitHub Pages project path.

Research snapshot: 25 November 2026. Missing or unverified prices, routes, room features, opening exceptions and social links are explicitly flagged. This is a shortlist, not a comprehensive Michelin inventory or a completed booking comparison. See `review.html` and `COORDINATION.md` for outstanding work and source irregularities.
