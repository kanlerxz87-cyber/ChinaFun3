# Evidence policy and repository audit

Checked 2026-11-25 (UTC). Initial repository contained only an 11-byte README and Git metadata. No application, data, tests, or outstanding file changes were present. Existing GitHub Pages configuration served main at `/`.

Research is a bounded Shanghai shortlist, NOT a complete China-wide city comparison or the full Michelin directory. It is a planning baseline, not a bookable package. Each source record in data.json states the exact fields observed. Official operator sites and Michelin (the rating authority) establish facts; social profiles provide previews only. Search snippets alone do not establish operational facts. A successful fetch does not guarantee a future URL or future opening schedule.

Unknown factual values are JSON null and render as an empty value with an adjacent Unverified label. Ratings are the live listing observed on the check date, not a promise of 2027 status. Costs are CNY, for two adults, unless explicitly marked otherwise in the source log. No currency conversion, tax assumptions, transit estimates, star-count guesses, or nightly-rate multiplication is used. Hotel checkout totals were not obtained; dates and occupancy rendered correctly for three Langham requests, but room-selection pages expose only 'From' and member figures excluding taxes and fees. They cannot establish seven-night final totals, availability of a guaranteed king, refund terms, or a cheapest week. No booking or payment was performed.

## Reproduction
Run `python3 scripts/build.py` then `python3 -m unittest discover -s tests -v`. Generated HTML is committed for GitHub Pages. All site assets are local; no API key, analytics, remote font, or build dependency. Internal links can be checked offline. External evidence was read via fetch_page in the research session; automated tests validate URL structure, not external availability. No claim of a comprehensive live external-link crawl.
