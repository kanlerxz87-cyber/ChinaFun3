How to use this site (mobile-friendly)

  1. Start here for the decision, then open Hotels to shortlist by area (Bund vs Lujiazui vs Jing'an).
  2. Open Restaurants — filter by Starred / Bib Gourmand / Selected and search by cuisine or district. Each row shows Michelin status, price tier (¥), open days/hours (or blank/unverified), official link, and social videos where verified.
  3. Open Activities — every activity is checked for ≤1h travel from the hotel areas via Shanghai Metro (official: shmetro.com).
  4. Open Dates & Itinerary for concrete 7-night options and a day-by-day template.
  5. Open Verification to audit every source and every flagged gap. Open Suggestions & Questions before deciding — it lists what must be answered first.

Data files (CSV + JSON) live in data/ and are the single source of truth for all tables. No manual input required — this page is generated from those files.
